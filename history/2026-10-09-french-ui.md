# French UI and French pull requests

Follows [`2026-10-07-english-only.md`](2026-10-07-english-only.md), which put everything in English, UI included.

## Decided
- **The UI is in French**: every text shown to players (home page, game page, statuses, server error messages, mode names and descriptions, ending reasons). The players (the uncle first) are French-speaking.
- Strings are **hard-coded in French for now**. A translation system may come later. This replaces the earlier advice to add i18n before any French UI.
- **Pull request titles and descriptions are in French**, so Rémi can review comfortably.
- Everything else stays in English: code, identifiers, comments, specs, history, commit messages, branch names.

## Points of attention
- Register: the UI uses "vous" ("À vous de jouer").
- Ending reasons (`GameMode.reasons`) are UI text, so they are in French too. The reason keys (`"checkmate"`, `"stalemate"`…) stay in English.
